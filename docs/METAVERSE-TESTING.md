# Metaverse — စစ်ဆေးရန် စာရင်း (Phase 13)

Deploy မတိုင်ခင် ဒီစာရင်းကို တစ်ခုချင်း ဖြတ်ပါ။ ★ ခြယ်ထားတဲ့အချက်တွေက
**မဖြစ်မနေ** — ကျန်တာက ကောင်းရင်ကောင်း၊ ဒါတွေက ကျရင် လူတွေ ထွက်သွားမယ်။

## 1. အလိုအလျောက် (automated)

```bash
cd server/metaverse
npm test            # ၃၅ ခု — protocol, auth, anti-cheat, room isolation,
                    # persistence, multi-task, token gate, vehicles, weather
node loadtest.js    # bot ၅၀ — CPU < 60% ဖြစ်ရမယ်
BOTS=800 SECONDS=30 node loadtest.js

cd ../..
npx tsc --noEmit    # client
npm run lint
```

Redis နဲ့ ဆိုင်တဲ့ test တွေက Redis မရှိရင် **skip** ဖြစ်တယ် (ကျတာ မဟုတ်ဘူး)။
တကယ်စမ်းချင်ရင်:

```bash
redis-server --port 6399 --daemonize yes --save "" --appendonly no
npm test
```

## 3. Feature matrix (လက်နဲ့)

### အခြေခံ
- [ ] ★ ဝင်တာနဲ့ လောက ပေါ်တယ် — WS server ကျနေရင်လည်း ပေါ်ရမယ်
- [ ] ★ ဧည့်သည်အဖြစ် ဝင်လို့ရတယ် (login မလို)
- [ ] W က ကင်မရာနဲ့ဝေးရာ သွားတယ်၊ **D က ညာ** (ဘယ် မဟုတ်ဘူး)
- [ ] နံရံကို ထောင့်စောင်းတိုးရင် လျှောသွားတယ်၊ ကပ်မနေဘူး
- [ ] Space နဲ့ ခုန်၊ Shift နဲ့ ပြေး

### Multiplayer
- [ ] ★ Tab ၂ ခုဖွင့်ရင် တစ်ယောက်ကိုတစ်ယောက် မြင်ရတယ် (👥 2)
- [ ] တစ်ဖက်က ရွှေ့ရင် ကျန်တစ်ဖက်မှာ ချောချောရွှေ့တယ် (ခုန်ခုန် မဟုတ်)
- [ ] Chat ရောက်တယ်၊ ★ **ဧည့်သည်ဆိုရင် "ဧည့်သည်" အမှတ်အသား ပါတယ်**
- [ ] နာမည်တံဆိပ်က ဝေးရင် မှိန်ပြီး ၄၀ မီတာမှာ ပျောက်တယ်
- [ ] ★ Server ကို restart လုပ်ရင် client က **ကိုယ့်ဘာသာ ပြန်ချိတ်တယ်**
- [ ] Map ၂ ခုက လူတွေ တစ်ယောက်ကိုတစ်ယောက် **မမြင်ရဘူး**

### လောက
- [ ] ★ Player ၂ ယောက်ရဲ့ နာရီ တူညီတယ်
- [ ] ည ကျရင် မီးအိမ်၊ ပြတင်းပေါက်တွေ လင်းတယ်
- [ ] Bloom ပိတ်ရင် FPS တက်တယ်၊ ★ ရွေးချယ်မှုက **နောက်တစ်ခါဝင်ရင် ကျန်တယ်**
- [ ] အသံဖွင့်ရင် တခြားသူရဲ့ ခြေသံ ဘယ်/ညာ ခွဲကြားရတယ်
- [ ] Minimap မှာ ကိုယ့်တြိဂံနဲ့ တခြားသူ အစိမ်းစက်တွေ ပေါ်တယ်
- [ ] Map ၄ ခုစလုံး ပြောင်းလို့ရတယ်၊ ★ ပြောင်းပြီး FPS မကျဘူး (memory leak)

### အခန်းများ
- [ ] တံခါးကနေ လျှောက်ဝင်လို့ရတယ် (loading မရှိ)
- [ ] နံရံကို ဖြတ်လို့မရဘူး
- [ ] အထဲမှာ အလင်းရှိတယ်၊ ★ ဝေးရင် ပရိဘောဂတွေ ပျောက်တယ် (FPS)

### ရာသီဥတု / ရေ / မီး
- [ ] ★ Player ၂ ယောက် ရာသီဥတု တူညီတယ်
- [ ] မိုးရွာချိန် ရွှေ့ရင် မိုးက လိုက်တယ် (ကွက်လပ် မရှိ)
- [ ] Storm မှာ လျှပ်စီးပြက်ပြီး အလင်း ခဏ ပြောင်းတယ်
- [ ] ရေထဲဝင်ရင် လမ်းလျှောက် နှေးတယ်
- [ ] မီးက တုန်ခါပြီး ပတ်ဝန်းကျင် ဝါရောင်လင်းတယ်၊ မိုးရွာရင် အားလျော့တယ်
- [ ] ★ ရာသီဥတု ပြောင်းလို့ FPS ၂၀% ထက် မကျဘူး

- [ ] ★ မောင်းသူ ပြတ်သွားရင် ယာဉ် လွတ်တယ်

## 5. Deploy မလုပ်ခင် နောက်ဆုံးစစ်ဆေးချက်

- [ ] `db/sql/metaverse.sql` ကို RDS မှာ apply လုပ်ပြီး၊ table ၄ ခု `rls = t`
- [ ] `MV_TICKET_SECRET` က Next.js ရော metaverse server ရော **တူညီတယ်**
- [ ] ★ Secret တွေ (`MV_TICKET_SECRET`, `DATABASE_URL`, `REDIS_URL`,
      `WEB3_RPC_URL`) က task-definition ရဲ့ `secrets` field မှာ —
      `environment` ထဲ **plain text မဟုတ်**
- [ ] ALB idle timeout ၃၀၀ စက္ကန့်၊ stickiness ဖွင့်ထား
- [ ] ACM cert + Route 53 — `wss://mv.gwave.cc` က browser ကနေ ချိတ်လို့ရတယ်
- [ ] `NEXT_PUBLIC_MV_WS_URL` ကို `/etc/gwave-web.env` မှာ ထည့်ပြီး
      **rebuild** (build time မှာ ဖုတ်တာမို့ redeploy တင် မလုံလောက်ဘူး)
- [ ] CSP မှာ အဲဒီ origin ပါတယ် (`next.config.mjs` က `NEXT_PUBLIC_MV_WS_URL`
      ကနေ အလိုအလျောက် တွက်တယ်)
